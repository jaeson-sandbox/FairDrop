FairDrop — Epic 9 approved proposal

A working prototype at the real 1024×768 window size. Click through it: choose a file, reveal or copy the link, simulate the receiver scanning, and finish.

Jump to Theme Motion

Everywhere

  • Every screen fades and rises in (~350ms, the existing decelerate curve).
  • Motion is built with CSS transitions, so older macOS WebKit just shows the screen instantly.
  • Reduced Motion drops all movement and keeps every state cue.

Ready

  • The QR code is the hero. The link stays hidden until you ask: Copy Link or Show Link.
  • The five paragraphs become two one-line notes. Firewall and receiver help move into “Trouble connecting?”.
  • The FILE tab and “Show full name” button are gone: long names wrap instead.

Errors

  • If the same item can simply be sent again, Try Again re-prepares that exact file and makes a fresh code. No picker.
  • If retrying can’t help (the item is gone or unsupported), the button becomes Choose Another.
  • If only a restart helps, there is just Dismiss.

Sending → Sent

  • The QR slot becomes a progress ring in the same place, so the card keeps its shape.
  • “Wire bytes” and the metric boxes become two plain figures.
  • Sent is one centred composition: the check draws, one receipt line, Send Another and Done. It no longer stacks on top of the drop zone.
