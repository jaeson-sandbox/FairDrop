No production Go or frontend module changed. The architecture delta is an asset
pipeline plus product verification: source JPEG → RGBA master → platform package,
with a Windows PE-resource test and post-build asset-drift check. Windows metadata
also gains FileVersion and changes its language key to 0409. The new resource test
reuses existing ICO/image helpers rather than creating another decoder.

`git_evidence.py` measures 1,287 net lines in `appicon_test.go`, 430 in
`exe_resources_windows_test.go`, 494 in the mutation driver, and 202 in the derivation
script. These are current file lengths too. Large verification machinery is a
maintenance cost, not evidence of a production god class. No layering violation or
new runtime dependency was found in this diff.

The concrete duplication defect is the size tuple in
`scripts/verify-asset-mutations.py:280-284`: its comment says it derives from
`wantIcoSizes`, but it repeats six literals. This is D-134. The hardcoded executable
path at `exe_resources_windows_test.go:43` duplicates `wails.json:4`; D-132 already
accepts that risk. **Instance: accept as-is under existing dispositions. Prevention:
derive mutation inventories from the canonical declaration.**

### F4 — Documentation and implementation differ

D-135 already captures the outdated gate enumeration, Story 6.2's neutral-language
I/O row, and missing calibration command in `build/README.md:38-40`. The frozen
story also specifies env gating while the implementation deliberately skips only
on absent output; its evidence explicitly records the rationale
(`evidence-6-2-*.md:98-107`). The behavior is reasonable, but the contract still differs.

The move to macOS exposes an additional portability limit in the README recipe:
lines 36-37 delete the Windows ICO and promise plain `wails build` will regenerate
it. Wails v2.15.0 `pkg/commands/build/packager.go:25-34` dispatches by target OS;
the Darwin packager calls `processDarwinIcon` at line 99. A native Mac build does
not regenerate a Windows ICO. This was established from dependency source; the
committed asset was not deleted to demonstrate it.

**Instance: propose documentation reconciliation, including a Windows-target
qualification on that recipe. Prevention: verify build instructions against each
supported host, and reconcile frozen behavior through an explicit owner decision.**

macOS 26.6.2, darwin/arm64. These local versions differ from CI's Go 1.26.7 and
Node 24 pins; the matching CI run supplies the pinned-environment evidence.

512, and 1024 pixel images. Every decoded image has alpha spanning 0–255 and a
transparent corner; the 1024 image's RGBA bytes exactly match `build/appicon.png`.
The 512 image was also visually inspected. No artwork or production code was changed.

nearby device, firewall, VoiceOver, or installer smoke was performed. The app was
left running for the owner. See `evidence-epic-6-retro-2026-09-20.md` for automated
results and CI job links. Regenerated bindings had only the known 0644→0755 mode
changes, which were restored; their content did not drift.
